# WiPeerKit

A Swift framework for secure peer-to-peer communication over local Wi-Fi networks using raw TCP sockets.

## Features

- 🔍 **mDNS/Bonjour Service Discovery**: Automatically discover devices on the local network
- 🔌 **Raw TCP Communication**: Direct socket communication using Apple's Network framework
- 🧱 **Byte Array Data Transfer**: Send and receive raw binary data with automatic message framing
- 🔐 **End-to-End Encryption**: AES-GCM encryption for all communications
- 🧩 **Modular Architecture**: Clean, testable design with protocol-based abstractions
- 🧪 **Fully Testable**: Comprehensive unit and integration tests included

## Requirements

- iOS 15.0+ / macOS 12.0+
- Swift 6.0+
- Xcode 16.0+
